# Cpp-code-2025

## 📚 Overview
A personal C++ learning repository that consolidates a variety of practice programs, assignments, and reference material collected during the author’s programming journey. It showcases fundamental concepts such as control flow, data types, class design, and algorithmic exercises. The repository also includes compiled binaries and a comprehensive OOP PDF for deeper study.

## ✨ Features
- **Class‑based examples** (`1 My name.cpp`, `2 Syntex Constructs.cpp`, etc.)
- **Data type and conversion exercises** (`6 Data Types.cpp`, `7 char datatype.cpp`, `8 character conversion.cpp`)
- **Algorithmic assignments** (loops, conditionals, swapping, table generation)
- **Compiled executables** (`*.exe`) for quick execution without recompilation
- **Reference PDF** `Object Oriented Programming (OOP) using C++(Freebooks.pk).pdf`

## 🛠️ Tech Stack
- **C++** (compatible with GCC, Clang, MSVC)
- Standard Library only – no external dependencies
- Build tools: `g++`/`clang++` or any IDE that supports C++ (VS Code, Visual Studio, CLion)

## 🚀 Getting Started
1. **Clone the repository**
   ```bash
   git clone https://github.com/imtiazaly/Cpp-code-2025.git
   cd Cpp-code-2025
   ```
2. **Compile a source file** (example for `6 Data Types.cpp`)
   ```bash
   g++ "6 Data Types.cpp" -o DataTypes
   ./DataTypes   # Windows: DataTypes.exe
   ```
   *Replace `g++` with your compiler of choice.*
3. **Run pre‑compiled binaries** directly:
   ```bash
   ./"6 Data Types.exe"
   ```
4. **Explore the PDF** for deeper OOP concepts.

## 📖 Usage Recommendations
- Open any `*.cpp` file in your preferred editor to study the code and modify it.
- Re‑compile after changes to see updated behavior.
- Use the provided executables for quick demonstration of concepts without building.
- The assignment folders contain grouped problems (e.g., loops, conditions) that can be tackled sequentially.

- Understand class definitions, constructors, and object-oriented principles.

- Build a portfolio of self‑contained C++ snippets for future reference.
